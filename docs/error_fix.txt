# Unity Scene Recovery Guide

## When to use this

Use this guide if Unity opens the project but one or more scenes appear empty, broken, or missing objects/cameras.

In this project, the scenes can be rebuilt from the editor builder scripts in `Assets/Editor`.

---

## Quick Fix

From the project root in PowerShell, run:

```powershell
& "C:\Program Files\Unity\Hub\Editor\6000.4.8f1\Editor\Unity.exe" `
  -batchmode `
  -quit `
  -projectPath "$PWD" `
  -executeMethod FullSceneRebuild.BuildAll `
  -logFile "$PWD\FullSceneRebuild.log"

Then check that the rebuild completed:

Select-String -Path FullSceneRebuild.log -Pattern `
"FULL SCENE REBUILD COMPLETE|Exception|error CS|FAILED"

A successful rebuild should contain:

=== FULL SCENE REBUILD COMPLETE ===
What the rebuild does

Assets/Editor/FullSceneRebuild.cs rebuilds the project using the existing Unity editor builder scripts.

It rebuilds:

Shared prefabs and systems
Player prefab
MuseumNight
Museum objects and props
Museum player and camera rig
Navigation and gameplay systems
HUD and minimap
FrozenCity terrain and content
ClockCore content
Audio, VFX, and scene polish
Noa/player presentation
Third-person camera configuration

This is the preferred recovery method because the scenes are generated from the project's builder scripts instead of relying entirely on potentially broken scene files.

Diagnose Before Rebuilding
1. Check Git status

Before doing anything:

git status

If you already have important uncommitted work, commit or back it up first.

2. Run the rebuild

Run the command from the Quick Fix section.

3. Check the end of the log
Get-Content FullSceneRebuild.log -Tail 60

Look for:

=== FULL SCENE REBUILD COMPLETE ===
Exiting batchmode successfully

Also check for errors:

Select-String -Path FullSceneRebuild.log -Pattern "error CS|Exception|FAILED"

Warnings about Unity licensing or graphics are not necessarily rebuild failures. The important indicators are:

error CS
Exception
builder-specific FAILED messages
missing FULL SCENE REBUILD COMPLETE
If MuseumNight Has No Camera

MuseumNight's camera depends on the Player existing first.

The full rebuild handles the correct order automatically:

Build the Museum
Add the Museum Player
Build the camera rig

Do not run MuseumSceneSetup.BuildCameraRigFromCommandLine first if the scene has no Player.

The correct recovery method is to run:

FullSceneRebuild.BuildAll

After rebuilding, check the log:

Select-String -Path FullSceneRebuild.log -Pattern `
"MUSEUM PLAYER OK|SETUP OK|SETUP FAILED|NOACAM OK"

A healthy MuseumNight rebuild should include messages similar to:

MUSEUM PLAYER OK
SETUP OK: camera rig built
NOACAM OK
If Only One Scene Is Broken

The individual builders can be run through Unity using -executeMethod.

Examples:

Museum
MuseumBuilder.BuildFromCommandLine
Museum camera rig
MuseumSceneSetup.BuildCameraRigFromCommandLine
FrozenCity
FrozenCityContentBuilder.BuildFromCommandLine
ClockCore
ClockCoreContentBuilder.BuildFromCommandLine

However, if multiple things are missing or the scene state is unclear, use the full rebuild instead.

After a Successful Rebuild

Check what Unity changed:

git status

Review the changes:

git diff --stat

If everything works correctly in Unity:

git add Assets/Editor/FullSceneRebuild.cs
git add Assets/Editor/FullSceneRebuild.cs.meta
git add Assets/Scenes

Then add any rebuilt prefabs, materials, or terrain files that are required:

git status

Review carefully before committing:

git diff --cached --stat

Then commit:

git commit -m "Rebuild project scenes and add scene rebuild tool"
git push
Important Rule
Do not manually copy old .unity files blindly.

Some historical versions of the scenes may use Unity's binary serialization format and may not be safely recoverable as text or compatible with the current project state.

The preferred recovery process is:

Broken/empty scene
        ↓
Run FullSceneRebuild
        ↓
Check FullSceneRebuild.log
        ↓
Open Unity and test scenes
        ↓
Review git changes
        ↓
Commit the working rebuilt state
